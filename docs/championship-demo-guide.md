# ContentLint AI — 심사용 설명·시연 가이드

## 한 문장

광고 문구를 게시하기 전에, 마케터가 **어떤 표현을 왜 고쳐야 하는지** 공식 근거와 함께 확인하고 수정 초안을 다시 검사하는 사전검수 도구입니다. 법률 자문이나 게시 승인이 아닙니다.

## 3분 시연 구성

1. **문제·대상 (20초)**: 일반 광고와 일반 식품을 다루는 마케터·판매자를 우선 대상으로 합니다. 문제는 긴 규정 목록을 읽는 것뿐 아니라, 자기 문구의 어떤 부분이 확인 대상인지 찾아 수정으로 연결하는 것입니다. 현재 실제 고객 인터뷰와 시간 절감 실험은 미실시입니다.
2. **텍스트 검사 (50초)**: 시작 화면의 ‘대표 예제 바로 분석’을 누릅니다. 설명용 미리보기와 실제 분석을 구분합니다. 수치 성과·최상급 표현을 서로 다른 핵심 이슈로 확인하고, 분석 완료 여부와 처리 시간을 함께 보여줍니다. 지연 시 진행 단계와 중단 버튼을 설명합니다.
3. **수정·재검사 (40초)**: 이슈를 눌러 원문 → 이유 → 수정 방향을 확인합니다. 새 증빙을 만들지 않고 수정안을 명시적으로 선택합니다. 실제 제품 정보와 맞는지 확인해야 하며, 완화한 문구도 재검사에서 잔여 이슈가 생길 수 있음을 보여줍니다. ‘이슈 0개’를 게시 승인으로 설명하지 않습니다.
4. **AI의 역할 (30초)**: 규칙은 명시적 패턴을, 검색은 공식 자료 후보를, AI는 부정문·조건·암시와 수정 방향을 처리합니다. 주장 인용이 원문에 있는지, 출처 인용이 검색 조항에 있는지는 코드가 검증합니다. 인용 연결을 법적 해석 정확도로 표현하지 않습니다.
5. **이미지 (20초)**: 가상 광고 이미지의 원본·읽어낸 글·시각 관찰을 구분합니다. 이미지의 문구 초안 재검사는 텍스트만 검사하며 원본 이미지가 수정된 것은 아닙니다. 좌표·영상 분석은 지원하지 않습니다.
6. **검증·한계·확장 (20초)**: 전체 평가의 성공과 실패를 같이 공개합니다. 추가 규정 분야는 팩·출처·테스트로 확장하는 구조이며, 출시 준비에는 전문가 평가, 실제 사용자 검증, 분산 비용 보호가 더 필요합니다.

이 시간 배분은 발표 구성안이지 서비스 완료 시간 보장이 아닙니다. 실제 대회의 제한 시간에 맞춰 조정해야 합니다.

## 장애 시 정직한 시연

- AI 미완료 + 규칙 결과: ‘부분 분석’ 배너를 보여주고 문맥 미검토를 설명합니다. 미리 계산한 결과를 실시간 AI 결과로 대신 보여주지 않습니다.
- 이미지 추출 실패: 읽지 못한 이미지를 분석했다고 주장하지 않습니다. 텍스트 입력으로 바꾸거나 실패 기록을 설명합니다.
- 외부 대체 계정 미구성: 같은 Vertex 재시도와 다른 제공자로의 전환을 구분합니다. 현재 다른 AI 제공자의 실제 인증·전환은 미검증입니다.
- 저장 결과: 저장 시각과 당시 상태를 표시하며 새 분석이나 최신 규정 검증이라고 설명하지 않습니다.

## 심사 기준별 제시할 증거

| 기준               | 보여줄 내용                                          | 아직 주장하면 안 되는 내용             |
| ------------------ | ---------------------------------------------------- | -------------------------------------- |
| 기획력             | 대상 사용자, 게시 전 문제, 수정 중심 동선            | 고객이 실제로 구매·사용한다는 검증     |
| 실현 가능성·기술력 | 배포된 동작, 입력 제한, 출처 검증, 실패 처리, 테스트 | 무중단·100% AI 성공·완전한 법률 검수   |
| 확장성             | 규정 팩·검색·제공자 인터페이스와 평가 구조           | 전 산업·영상 지원, 검증 없는 시장 규모 |
| AI 활용 적절성     | 규칙과 AI를 분리한 동일 데이터의 탐지·오탐 비교      | 출처 연결률을 법률 정확도라고 설명     |
| 발표 전달력        | 문제 → 검사 → 수정 → 재검사, 한계 포함               | 좋은 사례만 선별한 ‘전체 정확도’       |

실제 관측 수치는 최신 개선·검증 기록에서 실행 파일과 함께 확인하세요. “기존 30분 → 30초”는 아직 사용하지 않습니다.
