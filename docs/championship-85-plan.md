# 85점 이상을 목표로 하는 개선·검증 계획

시작일: 2026-09-17. 출발점은 운영 화면·코드·40개 개발 평가에 근거한 예선 심사위원 예상 70/100점이다. 실제 심사 점수, 투표, 발표는 보장할 수 없다. 자체 점수만 올려 완료하지 않고 아래 증거와 남은 한계를 함께 공개한다.

## 목표와 범위

일반 광고·일반 식품의 텍스트/정적 URL/이미지에 집중한다. 발견 → 근거 확인 → 사실을 추가하지 않는 수정 → 재검사 → 결과 가져가기를 짧고 신뢰할 수 있게 만든다. 새 산업, YouTube/영상, 전면 인프라 재작성은 핵심 품질 검증 전 착수하지 않는다. 기존에 구현된 분류 기능은 회귀 없이 보존한다.

## 제품 품질 목표 (대회 공식 기준 아님)

- 대표 시연의 전체 결과 반환과 최종 AI 완료를 별도로 측정한다. 제한된 반복 표본에서 최종 AI 완료율 95% 이상을 목표로 하며, 향후 100% 성공을 약속하지 않는다.
- 새 40개 데이터의 위험 사례에서 기대 유형 전체 탐지 85% 이상, 정상 사례 오탐 10% 이하를 목표로 한다. 규칙 대체·타입 불일치·분류 오류를 숨기지 않는다.
- 유효 이슈의 출처 ID 연결 100%를 목표로 하되, 출처 관련성·해석 정확성은 별도 사람 검토로 남긴다.
- 기존 개발셋을 보고 수정한 후 그 점수를 독립 검증이라고 부르지 않는다. 새 합성 사례도 전문가 검증셋으로 표현하지 않는다.
- 텍스트와 이미지의 최종 AI 분석 지연을 따로 공개한다. 규칙 대체의 빠른 응답으로 AI 지연 성적을 좋게 만들지 않는다.
- 사용자 효과는 도구 처리 시간이 아닌 동일 범위 작업의 검토 완료 시간과 품질로 평가한다. 참여자가 없으면 측정 준비 완료와 실제 효과 검증 완료를 구분한다.
- 포맷·린트·타입·전체 테스트·규정 인덱스·빌드 통과, 390px/중간 너비/데스크톱 화면, 오류/부분 분석/수정/재검사/보관의 확인 기록을 남긴다.

## 진행 원칙

1. 외부 AI 호출은 모의 테스트와 로컬 평가 후 소수 스모크부터 실행한다. 실패하면 원인을 수정하고 대량 호출부터 반복하지 않는다.
2. 인증 키·토큰은 읽어 출력하거나 문서에 보관하지 않는다. 새 계정/결제/권한 확대가 필요하면 사용자 결정을 요청한다.
3. 자료·사용자·평가 결과를 만들어내지 않는다. 공식 근거의 법적 의미 변경은 공식 자료를 확인한 뒤 수행한다.
4. 변경 파일별 별도 커밋으로 보관한다. 다른 사람의 변경과 무관한 파일을 수정하지 않는다.
5. 목표 달성 판정은 위 항목의 현행 증거와 동일한 채점 가정을 재검토한 뒤 내린다. 외부 의존성이 남으면 85점 달성을 주장하지 않는다.

## 진행 기록

- 2026-09-17: 작업 트리가 깨끗하며 마지막 운영 개선 이후 코드 변경이 없음을 확인. 기존 완료 기록과 새 목표를 분리하기 위해 이 계획을 작성. 실제 사용자 참여 가능 여부를 질문했고, 답변 대기 중에도 구현을 계속한다.
- 사용자는 현재 실제 사용자 참여자와 별도 AI API 계정을 구하기 어렵다고 답했다. 사용자 효과 검증과 별도 제공자 실인증을 미완료로 유지한다. 계정 생성·결제·약관 동의는 임의로 진행하지 않는다.
- 2026-09-20: 318개 단위·통합 테스트, 린트·타입·빌드 통과. 검증한 변경은 파일별 커밋 후 기존 Worker에 배포했다. 새 합성셋은 탐지 18/24, 최종 AI 완료 26/40, SAFE 오탐 0/16이다. 오탐 0건 중 6건은 규칙 대체이므로 AI의 정상 문맥 이해가 모두 확인된 것은 아니다. 85점 달성으로 판정하지 않는다.
- 후속 개선: 같은 Vertex의 3.6 Flash를 선택형 대체 모델로 추가했다. 324개 테스트 통과, 대표 데모 6/6 최종 AI 완료, 자연 발생한 호출 제한 5건 모두 실제 대체 모델로 복구했다. 별도 제공자 인증과는 다르며, 40개 첫 평가의 결과는 수정하지 않았다. 소규모 데모 개선만으로 85점 달성이나 전체 완료율 100%를 주장하지 않는다.
- 후속 개선도 기존 Worker에 배포했으며 운영 대표 문구 8.8초·핵심 이슈 2개·대체 모델 설정 표시를 확인했다. 전체 실행 수치와 배포 버전은 [개선·검증 기록](./championship-improvement-results-2026-09-20.md)에 보존했다.
