- [x] 기업·판매자 중심 첫 화면, 실제 지원하는 텍스트·URL·이미지 진입점, 한 번에 실행하는 대표 예제를 제공한다. 상세 설정과 예정 기능은 핵심 동선을 가리지 않는다.
- [x] 데스크톱·모바일 첫 결과 화면에 핵심 이슈와 수정 방향을 먼저 보여준다. 긴 규정·모델·호출 기록은 점진적으로 공개한다.

- [x] 처리 경과·실패·부분 AI 성공·규칙 대체를 정확히 표시하고, 반복 데모로 안정성과 지연을 측정한다. 다른 AI 제공자는 실제 인증이 있어야 활성화됐다고 표시한다.
- [x] 회귀 평가와 새 도전 사례 평가, 규칙/AI 비교, 출처 적합성·수정안의 사람 검토를 구분한다. 실제 실행하지 않은 성능을 주장하지 않는다.

- [x] 실제 검사 결과를 다시 볼 수 있는 제한된 브라우저 보관 기능을 제공하고, 보관 범위·삭제·이미지 원본 보관 여부를 명시한다.
