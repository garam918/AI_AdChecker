# 내부 도전 사례 v1

2026-09-15 서비스 감사 이후 작성한 **합성 문구 40개**다. 기존 회귀 문구와 구분하여 일반 광고와 일반 식품의 문맥 해석을 평가한다. 분야별 FLAG 12 / SAFE 8이다.

- 기존 규칙을 이해한 개발자가 작성했으므로 독립적인 블라인드 홀드아웃이나 전문가 정답셋이라고 부르지 않는다.
- FLAG는 잠재적 검토 신호를 기대한다는 뜻이지 위법 확정이 아니다. SAFE는 본 입력의 제한된 맥락에서 기대 이슈가 없다는 뜻이며, 적법 보장이 아니다.
- 기능·가격·원재료 등 중립적 설명의 사실성은 입력 전제로 둔다. 증빙 파일의 진위까지 검증하는 데이터는 아니다.
- 부정문, 약한 면책 문구 뒤의 상충 주장, 숫자 기호 없는 정량 성과, 체험담과 기능 안내를 포함한다.
- 실행 전 데이터 해시를 기록한다. 규칙과 AI에 **동일한 문구**를 주고 최종 AI 완료율·규칙 대체·오탐·미탐을 모두 남긴다.
- 출처 연결률을 출처 적합성이나 법적 정확도라고 표현하지 않는다. 생성된 JSON의 `analysis`와 `humanReview`를 사용해 출처 관련성·수정안 사실성·누락을 별도 검토한다.
- 이 사례를 보고 규칙을 수정한 뒤 다시 측정했다면 회귀/개발 결과로 보고하고, 새로운 독립 평가 데이터가 필요함을 밝힌다.

```sh
npm run eval:e2e -- --dataset=challenge
npm run eval:e2e -- --dataset=challenge --live
```

실제 API 호출은 과금될 수 있다. 결과는 모드와 실행 시각별 파일로 분리하며 이전 실행을 덮어쓰지 않는다. 실행 완료 여부와 실제 사례 수를 함께 보고한다.
