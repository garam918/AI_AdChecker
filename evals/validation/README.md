# 추가 합성 검증셋 · 2026-09-20

40개(위험 신호 24개, 정상 가정 16개), 일반 광고·일반 식품 각 20개입니다. 기존 개발셋을 보고 문맥 처리와 프롬프트를 수정한 뒤 새로 작성했고, 첫 실행 전에 기대 유형을 고정합니다. 위험 사례는 기재한 기대 유형이 **모두** 있어야 탐지 성공입니다.

이 데이터도 개발자가 작성한 합성 사례입니다. 전문가 검증 정답이나 실제 고객 표본, 법률상 적법·위법 판정이 아닙니다. 정상 가정은 기재된 중립 기능·조건·영양정보가 사실이라는 전제이며, 그 사실성을 시스템이 확인했다는 뜻이 아닙니다. 다른 주장 유형·문체를 대표하지 않습니다.

평가 결과에는 데이터 해시·구현 해시·최종 AI 완료·규칙 대체·오탐·미탐·사람 검토 대기를 함께 기록합니다. 이 결과를 보고 다시 수정하면 이후 실행은 개발 회귀 검사로 분류하고 첫 결과를 보존합니다. 기대 유형을 관측 출력에 맞춰 바꾸지 않습니다.

실행: `npm run eval:e2e -- --dataset=validation` (오프라인), `npm run eval:e2e -- --dataset=validation --live` (실제 API 사용료 발생, 순차 실행).
